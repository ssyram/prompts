# 技术报告写作理论调研

本目录研究如何把已有技术分析写成可理解、可评价的技术报告，并提出 `write-technical-report` 的修改方案。它是当前写作问题的研究入口，不沿用上一轮以完整研发史为中心的复盘框架。

## 先读

- [综合结论与来源](SYNTHESIS.md)：从任务确定必要内容，区分判断要求、构稿方法与面向指定读者的写法默认。
- [技能修改方案](../../SKILL-REVISION.md)：保留、替换与排除的内容，及它们在候选中的落点。
- [完整技能候选](../../SKILL-DRAFT.md)：可独立使用的正文，含构稿动作、条件化开头和实际改写示例。**尚未替换已安装技能。**

- [英文技术开头与摘要](../../01-openings.md)
- [中日及跨语言写作](../../02-multilingual.md)
