# 技术报告写作理论调研

本目录当前根目标是：以 指定读者 为重点读者，固定“怎样快速传递 idea 的 technical report”这一写作问题。它不继续设计 Tool Auth Lang；`write-technical-report` 只是后续可用于承载该方法的工件。

## 先读

- [当前 QPDI 记录](QPDI.md)：本轮已确认的根目标，以及候选 Q/D、边界和既有稿件的同步义务。
- [综合结论与来源](SYNTHESIS.md)：范围较宽的既有研究依据；其中结论不因已写成就自动成为当前根目标。
- [技能修改方案](SKILL-REVISION.md)：前轮候选的保留、替换与排除方案，待按当前 Q/D 对账。
- [完整技能候选](SKILL-DRAFT.md)：前轮候选正文，尚未按本轮根目标批准或替换已安装技能。
