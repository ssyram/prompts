# Research：中文、日文及跨语言科技写作的结构与推进

## Summary

本路证据支持把“组织信息”提前到逐句润色之前：先确定全文与各部分的目的、信息归属和推进关系，再补材料；但没有证据证明技术报告必须以类别定义开头，或只能从WHAT／WHY／背景三种入口中选择。中文期刊指导与日文学术报告指南都重视目的、必要信息和关系清楚；它们属于特定文类的规范性建议，不能上升为民族思维规律，也尚未证明某种写法使指定读者阅读最快。

## Findings

### 1. 建立体系：不仅先说“大概是什么”，还要给各部分分配任务

**Claim：** 名古屋大学指南把结构明确拆成“写哪些信息、按什么顺序、各写多少”，先确定全文的主目的和部分的副次目的，再安排节与段落。[S1] **Support：direct evidence（规范性指南）；Confidence：high。**

其「構成要素を配列する」「アウトラインを作成する」要求将部分目的与信息对应，提纲还可以预置文献、图表和段落主题句。这比“先轮廓后细节”更有检查力：某个细节不仅要被定义，还应有可辨认的归属和任务。原语「アウトライン」是提纲；「パラグラフ」在此特指围绕一个目的的文字单位，不等同于任何排版分段。

**本任务推导：** 可在起草前列出“对象定位—需要解释的方面—每方面承担的说明任务”，然后把机制、例子、证据放回相应位置。类别模板只是生成这些位置的一种办法，不是来源要求：语言可以按表达对象、基本构件、含义和边界展开；不能因另一份报告按系统输入输出展开，就照搬它的对象类别。

边界有二：S1主要讨论学生学术报告，其常见主目的为合理论证研究问题的答案，并明确允许其他目的；它也允许研究和提纲相互调整。因此，“先搭架构”不能变成“未写完固定提纲就不许思考”，更不意味着所有报告都要证明一个研究假说。

### 2. 局部推进：段落要有可辨认的任务，关系须稳定，而非堆连接词

**Claim：** S1要求读者无需前后重读，就能明白段落目的与强调点；建议排除无关信息，使逻辑、因果、抽象度或重要度的顺序清楚。[S1，“パラグラフ・ライティング”至“情報の流れの一定性”] **Support：direct evidence（指南及教学实例）；Confidence：high。**

可核验例：指南把“世界→日本→东亚”的层级跳跃改成“世界→东亚→日本”；另把事件叙述改为时间顺序。其加拿大多民族国家示例删除部分顺接词，说明关系清楚不等于每句加“因此”。这些是教学改写，不是阅读实验，不能据此声称已测出理解速度提升。

「トピックセンテンス」（主题句）说明段落的目的及强调点；原文说常见于段首“或段末”，并允许重复强调点。这直接限制“每段首句必须给结论”“一切重复都删”的绝对化做法。

**本任务推导：** 每段检查三个问题：本段让读者知道什么？支持这个认识的说明是否足够？下一句与当前认识是什么关系？若细节无法回答第三问，先补它的归属，不先进行词语压缩。面向快速评审，可优先尝试段首主题句，但应标作任务默认值，而非日语或中文的普遍定律。

### 3. 摘要与引言功能不同；“信息充分”不等于“所有背景都要写”

**Claim：** 《光学仪器》编辑张磊区分摘要的独立概括功能与引言的研究理由说明功能；同时指出引言过短会遗漏现状与问题，过长会重讲读者几乎都知道的理论方法。[S2，§1.2—1.4] **Support：direct evidence（编辑经验及规范建议）；Confidence：high。**

这支持按目标读者决定背景量，而不是固定“先把WHY重讲一遍”。但“指定读者知道某概念”仍是本任务给定的读者画像，不是文献替我们验证的事实。可以保留一句本稿范围供读者核对，不必重演完整研发动机。

长江大学期刊中心材料区分报道性、指示性、报道—指示性摘要：指示性摘要可以只概述论题或目的；其“目的—方法—结果—结论”建议主要面向学术科技期刊的报道性摘要。[S3，§1—3] **Support：direct evidence；Confidence：high。** 因而不能把四要素机械当成所有短文的章序，也不能逼尚未实现的方案编造“结果”。

重要反例是S3的滤波器编辑实例：原稿“各项指标均达到了设计的要求”被换成具体范围和误差，同时补齐功能转换方法，摘要由151字增至218字。[§4.1例2] 它支持“为充分说明而增加文字”，不支持“越短越清晰”；但作者未进行受控阅读实验，其坚持200—300字的建议也不能移植成指定读者报告的长度标准。

### 4. 开头有多种功能，不存在本路证实的唯一顺序

**Claim：** 在取得的实例中，目的、问题和研究定位都可充当入口，选择受文类任务制约。[S2摘要与引言；S3例2、例3；S4摘要] **Support：interpretation（对个别文本的功能归纳）；Confidence：medium。**

- S2摘要以提高论文质量的目的开头，再交代基于稿件审理的总结工作；它的引言则从科技论文的作用展开。一个文本内部，两处开头就承担不同任务。
- S3例3不是先给“污废水处理系统”的类别定义，而是先交代曝气不均、指标超标等具体问题，再说明改造方案。它是问题情境，不是包含人物行动全过程的完整故事。
- S4英文摘要先定位既有研究偏重moves、较少关注steps，再引出本研究。这是研究缺口入口，不等于面向委托人的产品介绍。

**本任务推导：** 对不熟悉对象、需要评估方案的读者，“类别＋用途＋本文讨论范围”是值得试用的入口；对已熟悉对象而不知变化原因的读者，可从具体问题或场景入手。场景需要及时点明它代表哪类问题；类别需要继续展开相关方面，否则都可能只增加标签。尚无直接比较证据支持这两种入口孰优，也不能由摘要的功能单元数量推出开头模式只有固定几种。

### 5. 跨语言比较：先辨认样本，不能把期刊差异叫作语言差异

**Claim：** 赵永青等（2019）比较中国与国际领先期刊的1251篇实证论文英文摘要，摘要报告了研究定位、讨论环节中推介性步骤的差异。[S4，官方摘要] **Support：direct evidence（原始语料研究的摘要）；Confidence：high，限于摘要明确报告的样本与结论。**

关键是这些文本都是英文，不能转述成“中文比英文更间接”。作者使用的「moves／steps」（语步／步骤）是交际功能层级，不是句数，也不是固定开头配方。所谓“推介性”包括强调研究价值及参与学术对话，不宜未经分析就等同于空洞夸赞。

本次仅取得S4摘要，未读方法、编码一致性、学科分布和统计表，不能独立评估其差异解释。真正的中英摘要比较候选Li（2020）及中英引言比较Wang与Yang（2010）原页被机器人验证拦截，未采用搜索摘要中的频率数字。日语原语检索取得可靠大学指南，但未取得足以核验的日英科技摘要对照全文；检出的工程研究中有“日本学生写的英文”对“国际期刊英文”，亦不能冒充日语对英语。

因此，本路能迁移的是目的、信息组织和受众适配的检查；不能迁移的是民族风格判断，或把学生论文、实证论文摘要的惯例当作中文指定读者方案报告的硬规则。

## Contradictions：对候选原则的支持与收窄

- **支持：** 先配置内容与结构，再润色句子；先确保任务所需信息齐备，再裁剪。S1、S3提供可操作依据，木下是雄著作的出版社介绍也强调内容取舍与组织，而非仅追求句子漂亮。[S5，仅出版介绍，未读原著]
- **需要收窄：** “先WHAT再HOW”可作为不熟悉对象时的默认尝试，不能当作首句规则；问题入口是真实反例。“回应约定要求”适合本次委托，大学指南提供的更一般表述是按目的和读者理解选择信息，并未建立普适的作者—读者契约理论。
- **来源自身也有限制：** S3一面区分摘要类别，一面后文将四要素和字数要求写得较绝对；应依其科技期刊编辑语境理解。其修订摘要仍保留“很方便地”等表达，故不能用该来源证明应禁止所有评价性修饰语；本路也未验证这些词是否妨碍理解。

## 技能修改候选与下一步

仅建议三处候选，不在本轮执行：①把“组织正文”前移，在逐句检查之前写明全文目的、对象定位、各部分任务及细节归属；②将固定“用途与验收要求→方案→案例”改成按读者缺少什么选择入口，保留原序列作为委托型方案报告候选；③核对时增加“只读标题与各段关键句，能否还原对象、主要关系和结论”的试读，再核对各段支持材料是否充分。最后一项是本任务推导，不是已验证量表。

不建议加入民族写作模式、起承转合口号、强制IMRaD、强制四要素、所有主题句置于段首、所有报告都须完整动机故事。最有价值的后续不是继续堆理论，而是对同一段中文方案制作两种入口，让目标读者指出何处尚不能定位对象与细节；那才开始检验当前迁移建议。
