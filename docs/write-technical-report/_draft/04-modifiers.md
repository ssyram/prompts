# Research：技术报告中的修饰语、限定与信息压缩

## Summary

问题不在修饰词是否“有意义”，而在读者能否恢复它修饰谁、表达什么关系、限制哪项主张，以及凭什么成立。现有技能保留限定、拒绝黑名单的方向有依据，但“信息藏词里则展开”过于一刀切：应先辨认功能，再决定保留、移位、显化关系、补依据或删除；字数最少与逐项展开都不是普遍最优。

## Findings

### 1. 修饰语首先是语义和篇章功能，不是待删词类

**判断：**需区分对象分类、条件范围、认识立场、程度评价和篇章连接。**依据：**NASA指南§3、§3.8.1；Hyland摘要；Biber与Gray §4–6。[S1–S3] **支持类型：**规范性指南、语料描述；**置信度：高（功能区分），中（具体改写选择）。**

“只读连接”划定对象类别；“仅在提交前检查”限定时间和适用范围；“现有结果提示”表达证据允许的确信程度；“因此”标出推理关系。它们的贡献未必能被“对象、动作、条件、范围、数量、结果”完全捕获。现有技能虽明说保留“可能”，其总判据却没有显式包含证据状态与句际关系，容易产生前后不一致。

空泛评价也不等于所有评价。面向决策的技术报告需要比较、推荐和解释重要性；真正应删的是未承担当前任务的赞美，不是所有作者判断。**本任务推导：**“显著改善体验”若无比较对象、指标或用户证据，应删或标待证；若前文已有对照数据，结论句“因此，本场景优先选择A”有决策功能，不必再次展开全部测量。这里的合法性来自可回溯依据，不来自“优先”一词本身。

### 2. 不确定性不等于含糊，hedging也不只是不确定性

**判断：**删除缓和语可能把审慎推断改成事实断言；但保留“可能”不能自动使主张精确。**依据：**Hyland对26篇分子生物学研究文章的语境分析，摘要明确指出hedging兼有精确、谨慎、同行互动和促成讨论等功能。[S3] **支持类型：**语料研究摘要中的作者解释；**置信度：中，未读正文。**

必须拆开两件事：①说的是哪种事件、条件和范围；②作者对这个命题有多少把握。例如在故障原因尚未确认的报告中：

- 不足：“系统可能存在较严重的稳定性问题。”事件、程度、条件都待猜。
- 较好：“日志记录了三次重连失败；原因尚未确认，不能据此判断是否由升级触发。”

这是**自拟例及任务推导**，不是论文实验材料。后者仍保留未知，而非凭空补上概率。“可能”可继续使用，但应让其作用域可识别；不要求所有探索性观察都量化，更不能把修辞习惯强行翻译成未经校准的数值概率。

现有规则对“限定会改变判断则保留”应当支持；但“改变判断”应包括主张强度和证据来源，不只包括执行条件。反过来，连续堆叠“大概、可能、似乎”也未必提供额外区分，应检查是否各自限定不同内容。

### 3. 有定义的词不保证本句关系清楚

**判断：**词义识别与关系恢复是两个检查。**依据：**NASA §3明确指出词典有定义不等于适合表达当前意思；Biber与Gray §4区分指称明确和语义关系隐含。[S1–S2] **支持类型：**指南及直接语言分析；**置信度：高。**

Biber与Gray的原例中，`pressure hose`表示承受压力的软管，`pressure ratio`涉及压力的比率；前置词相同，关系不同。`reflection of Alfven waves`对非专家还可能留下“波反射别的东西，还是波被反射”的选择。逐词查字典不能决定这些关系。

因此，“术语已解释”不能替代“本句对象和作用域清楚”。**本任务推导例：**“默认禁止外部写入规则”即使每词都熟悉，也可能指“默认启用的禁写规则”或“禁止外部改写规则本身”。解决办法首先是选择并明写关系，而不是给“默认”“外部”各添一段定义。若材料无法确定，应提问或标注，不能替作者设计。

### 4. 压缩确有价值；修饰链越长越差并非实验证明的普遍律

**判断：**专业表达常靠名词短语压缩信息，但是否造成负担与读者知识、词项及语境有关。**依据：**Biber与Gray §2–6；Landwehr等§4–8。[S2、S4] **支持类型：**语料描述、眼动语料经验研究；**置信度：高（样本内结果），低（直接推广中文报告）。**

Biber与Gray比较约300万词研究文章与约420万词会话，发现学术文章更多采用短语嵌套，而非会话式从句展开。他们解释专家可快速利用压缩表达，新手更难恢复隐含关系；这是作者的功能解释，**不是阅读速度对照实验**。

更直接的2025年研究分析75名德语母语大学生阅读生物学、物理学教材的眼动：三个构成成分相对两个成分的额外首次阅读时间，只在物理文本的跨领域新手组显著；生物文本无对应显著效应。另一结构比较也只在一个领域出现。作者承认词项稀少、类别不均衡和泛化问题。这既不支持“修饰链人人都难”，也不证明专家总能无代价解码。它没有比较同一内容的紧凑版与拆句版，更没有证明理解正确率同步变化。

NASA给出有上下文的正反例：独立表达时，`test design`和`review board`有压缩价值；连成`test design option review board`则遮蔽关系，宜改为`a board for reviewing test design options`。[S1，§3.8.1] 注意：指南选择了显式关系短语，**没有拆成五句**。

### 5. 更短不必更快；拆句也可能破坏焦点和连贯

**判断：**需要优化的是恢复关系的总负担，不是修饰词数量。**依据：**NASA §3.1；Gopen与Swan的“Subject-Verb Separation”“The Stress Position”“The Topic Position”。[S1、S5] **支持类型：**规范性建议及个别文本改写；**置信度：中，非效果实验。**

Gopen与Swan分析一个42词句子：主语和谓语间隔23词，但重点不是42太长，而是插入结构把可能重要的信息降成旁枝。他们给出不同改写，并承认只有原作者能决定哪项信息重要。另一个例子即使解释专业知识，首尾关系和段落推进仍不清楚；这直接反对“术语懂了就够了”。

**本任务推导：**如果“只读缓存”已经是双方稳定使用的类别，每次改写成“这是一个缓存。它只能读取……”会增加句际接合和重复定位，也可能把背景性质误强调为新结论。相反，若当前争点正是“只读是否包含刷新”，就应局部展开其边界。更好的选择集是：保留稳定词块／移动修饰位置／补介词或动词／并列列出条件／必要时拆句，而非只有删与展开。

## Contradictions：对现有技能的收窄

没有发现需要实行词性黑名单的证据。来源中有真实张力：学术共同体实际重视压缩，而写作指南重视显化；Biber与Gray自己没有把两者的最优平衡解决掉。

- **保留：**不凭词性删除；删除后核查主张是否变强；不能以设计补含糊；信息充分先于裁剪。
- **修改：**“信息藏词里则展开”改成“关键关系不能由目标读者稳定恢复时，显化该关系”。有意义不等于适合保留，承载信息也不等于必须扩成句。
- **修改：**“称赞、强调、替结论表态都不保留”过强。应区分无依据造势与有依据的比较结论；区别放在功能和依据上。
- **收窄：**熟悉术语无需反复释义，但新对象、新关系、新边界不能以术语熟悉为由略过。

## 候选技能修改：四项可判定检查

以下是**综合来源后的任务推导**，不是已验证的写作算法：

1. **挂接检查：**给关键修饰语画出它限定的中心词或命题；出现两种影响结论的读法，就重排或补关系词。
2. **对比检查：**“快、稳、灵活”等用于论证时，能否指出比较对象、条件和依据？找不到则删、降为目标或标待证，不编指标。
3. **主张检查：**删除前后，对象集合、否定范围、条件、确信程度和逻辑连接是否改变？改变则不可按冗余处理。
4. **读者检查：**请目标读者复述“谁对谁做什么、何时成立、哪部分未确定”。区分术语认不出与关系理解错；重要段落可比较两版，分别观察用时和复述错误，不用词频下降代替理解测试。

探索性输入可保留作者尚未拆开的候选性质，作为待澄清材料；定稿则应把影响结论的歧义解决或明确标出。这是阶段管理建议，不是“草稿可以任意含糊”的研究结论。现有材料没有测AI理解修饰链，不能断言AI比人可靠，亦不能据此免除给AI输入时的范围澄清。

不建议加入：形容词黑名单、修饰成分硬上限、所有评价改数字、所有长句拆短句，或要求每次重释术语。

## Missing evidence 与 Next steps

本路已回答规则应如何收窄；尚不能给出中文报告的最佳修饰链长度或展开阈值。Hyland仅核到原文摘要，不能据其细分所有hedging类型；眼动研究不是中文报告、AI输入或同内容改写实验。若继续研究，最有价值的是对真实目标读者做少量释义比较，而不是继续堆写作格言。
