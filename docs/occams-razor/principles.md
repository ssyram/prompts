# Occam's Razor — Principles（QPDI Q）

## Task Overview

**问题对象：**一个作用于设计、研究、执行与表达的 `/occams-razor` skill：围绕当前真实意图形成最小充分结果。

**当前状态：**核心方向已确认；具体设计与文案仍需应用测试。

**Q 的职责：**规定什么结果值得保留，以及必要性判断成立于怎样的工作世界。分析职责、递归结构与裁剪方法属于下游 P/D。

**下游：**[`architecture.md`](architecture.md) 承接 P/D；[`current/occams-razor.md`](../../current/occams-razor.md) 落实 I。

## 整体问题意识

工作会不断产生新的解释、结构和行动。它们可能承担真实需要，也可能只因已经出现而继续生长；反过来，压缩也可能删掉完成事情所需的内容。

Occam's Razor 不以少为目标。它要求结果充分实现当前真实意图，并且其中的复杂度都具有当前存在理由。

---

## Q.I — Intention

### Q.I.1 — 当前意图的最小充分实现

**采纳状态：**已确认方向；精确定义仍可由应用测试校正。

压缩后的结果必须仍足以实现用户当前真实意图及其实际用途。保留的概念、结构、行动、验证和说明必须对此具有当前贡献；将其删除且不作充分替代，会损害真实性、明确约束、责任边界或目的实现。

这不等于追求篇幅最短、结构最少或只防止失败。真实意图可以要求复杂设计、正向能力、具体落实和充分验证。当前判断也不声称获得唯一的全局最小方案。

仅以可能有用、形式完整、惯例、既有投入、已经命名或无证据风险为理由的复杂度，不取得保留资格。

## Q.A — Assumption / Acknowledgement

### Q.A.1 — 当前意图只能形成有界工作解释

**采纳状态：**已确认方向。

当前请求、用户纠正、紧邻上下文、明确约束、权威工件和已观察事实共同支持一个当前工作解释；它说明正在处理什么、结果用于什么和边界在哪里，但不是对用户心理与未见世界的完整认识。

用于形成结果的讨论、分析和执行内容只是证据，不自动成为问题对象或交付内容。新证据改变工作解释时，只由旧解释支撑的内容失去原有根据。

### Q.A.2 — 必要性是逐层、关系性的规定

**采纳状态：**已确认方向。

必要性只相对于当前意图、事实、约束、作用域和已接受的上层选择成立。同一对象在一层可以是候选；它被选定后，又成为下一层分析的前提，其内部内容则成为新的候选。

问题通常只能规定所需能力与性质，不能唯一推出具体方案。方案具有自身能力和限制；选定方案以后，上层要求与方案自身规定共同产生内部组件的条件性必要。因此，必要作用不蕴含某个字段、文件、阶段或载体必然存在。

这种层级变化可以继续发生，直到当前作用域中的叶子内容；上层选择改变时，由它建立的下层必要性也必须重新判断。

## Q.E — Experience

### Q.E.1 — 生成过程会替代真实对象

**事实状态：**多次本地会话观察；不外推为普遍规律。

临时解释、显著词语、已有方案和执行过程曾被直接升格为当前工作对象。候选被命名和展开后，会继续产生只为自身服务的下游义务；根解释被纠正后，这些内容仍可能残留。

**经验关联：**当前正在讨论、已经存在或内部一致，都不能代替其对真实意图的贡献。

### Q.E.2 — 局部理由不能证明整体必要

**事实状态：**多次本地设计观察。

内容之间的相互依赖会使每一项局部看来都有理由，但它们组成的整体仍可能没有外部贡献；父选择失效时，专属后代也不会自动消失。

**经验关联：**必要性必须同时检查单项、依赖关系和重组后的整体。

### Q.E.3 — 过度压缩会转移未完成工作

**事实状态：**本地设计观察。

结果变短或字段减少以后，使用者仍可能被迫补做被省略的判断、接口或条件；定义、来源或前提被删除而其使用仍保留时，也会把语义重建转移给使用者。复杂度没有消失，只是离开当前产物并转移给了下游。

**经验关联：**压缩完成与否只能由真实用途的充分实现判断，不能由形式规模判断。

### Q.E.4 — 任务重校准通常改善语境恢复，但并不完美

**事实状态：**既有长程会话中的重复使用与用户评价；只支持有限经验结论。

**经验对象：**`/recalibration`，内容 SHA-256 `cd8604c4eee833a0845398d6655522097106bc1d83290a03f6f03c0da2ddc7ab`。

重新阅读完整委托、恢复最终目标与仍有效的中间目标、区分实际状态和最近过程焦点，通常能比沿用当前对话框架更好地恢复工作方向；它仍可能误认目标、状态或结构，不能充当正确性保证。

**经验关联：**O-R 可以采用这种重校准动作建立分析语境，但必须继续核对来源、目标链和当前事实；不继承其专用 stack 或输出格式。

## Q → P/D handoff

- Q.I.1 + Q.A.1 + Q.E.1/Q.E.4 → 从最终目标、仍有效的中间目标和当前事实重校准分析语境，排除过程框架替代，并保留来源核对与纠错；
- Q.I.1 + Q.A.2 → 在已接受的问题设定与对象中分析必要性，只执行排除与保持语义的收缩，不承担未决内容的综合；
- Q.A.2 + Q.E.1–Q.E.2 → 将同一必要性分析递归适用于当前作用域中的每个后代层级，并清理失去上层根据的内容；
- Q.I.1 + Q.E.2–Q.E.3 → 裁剪后重新检查 Sound、Complete 与责任边界，以 Concise 作为本 skill 的直接评价对象；
- Q.I.1 + Q.A.1 → 直接交付当前用途需要的结果，只显式说明会改变理解或行动的边界。

具体 P、M、R 与 I 的承接见 [`architecture.md`](architecture.md)。
