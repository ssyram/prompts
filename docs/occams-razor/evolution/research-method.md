# 客观考古与后见学习如何分层

## 0. 最高原则

考古不负责证明今天的成果正确，也不负责把过去整理成通向今天的道路。它只在公开限制内尽可能恢复当时可观察的消息、工件、次序、分支和修改。

任何后来形成的价值或解释框架都不得支配历史记录。后来理论回投只是其中一种违规；最终版本、后来接受、发布成功、当前兴趣和“对今天有用”同样可能构成辉格式筛选。

绝对零组织不可能。建立语料范围、匿名化、排序和省略纯工具回显都需要选择。可执行要求是：

1. 选择规则公开；
2. 选择规则不以最终胜出结果为标准；
3. 可观察记录与作者解释分开；
4. 解释不能反向修改记录；
5. 不确定处报告缺口，不用顺畅故事补齐。

## 1. 三种文件承担不同责任

| 层 | 回答什么 | 可以使用什么 | 不得做什么 |
|---|---|---|---|
| 客观考古 | 当时实际出现了什么 | 消息、同时期工件、diff、分支、顺序、显式回复关系 | 判断历史意义、贡献大小、成败、必然性或终点 |
| 后见学习 | 今天可从记录提出什么解释 | 考古事件引用、明确推导、反例和当前评价标准 | 把解释改写成当时意识或源事实 |
| 生产规范 | 当前应如何执行 | 已接受设计、验证和明确决策 | 用当前规范筛选或美化它自己的起源 |

依据关系是：

```text
原始材料
→ archaeology.md
→ concept-formation.md / reflection.md

research-method.md
→ 约束上述提取过程
```

生产文件是被观察的工件之一，不是考古裁判。

## 2. 先确定语料全集，不先选主线

开始阅读前记录：

- 哪些会话、工件和外部材料属于调查范围；
- 每个会话有哪些分支与叶子；
- 哪些记录因公开限制只能匿名引用；
- 哪些记录无法取得；
- 去重和省略规则是什么。

不能只从最终采用叶反向取祖先，再把其他分支称为旁支。若一个分支在当时真实出现并含有实质判断，它就是发生史的一部分；是否进入最终工件是另一项可观察事实。

若材料量过大，可以分批，但批次划分应按来源、时间或稳定结构，不按“对最终理论是否重要”。

## 3. 只允许结构性省略

可以省略：

- 不含判断内容的工具回显；
- 同一状态的机械重复；
- 纯等待和没有新增内容的继续指令；
- 因公开脱敏必须隐藏的定位信息。

不能仅因以下理由省略：

- 后来没有采用；
- 被证明错误；
- 与当前理论无关；
- 只是绕路；
- 破坏一条顺畅的形成故事；
- 无法解释它对最终成果的贡献。

省略规则只判断“有没有可观察的新事件”，不判断“有没有历史价值”。

## 4. 客观事件的最小 schema

每条事件只记录：

```text
匿名事件号
来源别名与分支位置
相对时间或局部顺序
说话者
当时直接提出的问题或要求
消息直接给出的区分、主张或否定
同时期工件的可观察增删
显式回复、引用或分支关系
记录缺口
```

不得在事件内设置：

- 概念作用；
- 历史地位；
- 对最终框架的贡献；
- 成功/失败评分；
- “为后来准备了什么”；
- “真正意味着什么”。

如果下一条消息反对上一条，分别记录两条事件，并建立“后者显式反对前者”的关系。不能据此重命名前一条。

## 5. 描述文本结构，不按后来概念评价

可以写：

> 候选文件包含 `Object`、`Necessity`、`Directness`、停止条件和固定输出字段。

不能在考古层续写：

> 它尚无 `F / X / X|F`，所以只是一套经验规则。

后一句使用后来框架作比较。它可以进入学习文件，但必须列出当前比较标准和对应事件。

同理，可以记录某个术语首次出现；不能因为它后来成为生产 notation，就称该回合为“闭合”“突破”或“关键统一”。

## 6. 工件账只写可观察差异

每个版本记录：

- 文件身份与版本顺序；
- 标题和主要段落；
- 新增的原句、字段或步骤；
- 删除的原句、字段或步骤；
- 重命名与移动；
- 当时附带的验证结果；
- 谁在下一事件中接受、反对或继续修改。

“新增能力”“更完整”“更正确”“删过头”不是直接 diff。若要使用，移入后见比较并明确评价标准。

手工编辑无法逐字符恢复时，只报告可取得的前后快照，不推测编辑过程。

## 7. 分支账不得以胜出为权威

对每个分叉分别记录：

- 共享祖先；
- 分叉消息；
- 各分支实际内容；
- 哪个分支后来继续产生工件；
- 哪个分支停止，以及源记录是否说明原因。

“采用分支”只表示后续工件沿它继续，不表示它更真实、更有价值或更接近终点。

没有证据说明某分支为何停止时，写“后续未沿用”；不要写“被淘汰”“错误分支”或“完成纠偏”。

## 8. 顺序不自动构成因果

考古层可以建立因果关系的最低证据是：

- 后一消息明确引用前一事件并说它促成了当前动作；或
- 可观察操作具有直接输入—输出关系，例如一条编辑命令实际改变了文件。

reply 关系只证明回复对象，未必证明思想来源。时间邻近、相同词语、后来的可解释性和最终结构相似都不够。

无法闭合时只写：

```text
事件 A 先于事件 B
B 使用了与 A 相同的词
现有记录没有说明 B 是否来自 A
```

## 9. 禁用作者声音中的胜负词

以下词只有在逐字术语、参与者评价或后见学习层中才能使用：

- 正确、错误、偏航、纠偏；
- 成功、失败、生产性失败；
- 过度、删过头；
- 前身、伏笔、准备；
- 关键、转折、突破；
- 闭合、成熟、稳定；
- 真正、本质、必然；
- 迫使、逼出、直接导致。

考古层若保留参与者评价，必须写明主语：

> 下一事件中，用户称该删除削弱了分析性与递归。

不能改成：

> 这次删除削弱了本质规定。

## 10. 后见学习使用 claim card

从 archaeology 向学习文件提取时，每个判断至少写明：

```text
当前主张
采用的价值或理论框架
支持事件
从事件到主张的推导
可能反例或替代解释
证据状态
```

例如“某回合是 `X|F` 的概念前身”至少需要说明：

1. 今天如何定义“前身”；
2. 早期消息实际包含哪些关系；
3. 哪些后来角色在其中不存在；
4. 为什么结构相似足以建立谱系，而非只是今天可以重述；
5. 是否存在另一条同样合理的来源路径。

学习文件可以有判断，但不得把判断伪装成考古恢复。

## 11. 三类学习文件可以怎样反哺

### `concept-formation.md`

可提出概念谱系、版本比较和当前理性重构。每个阶段必须引用 archaeology 事件，并区分：

- 当时原话；
- 后来显式承接；
- 当前解释。

### `reflection.md`

可保存方法教训和价值判断。每条经验应指出它来自哪些事件，以及它适用到什么范围；不能把一个案例直接升为普遍规律。

### `README.md`

只说明目录原则、文件关系和阅读入口。若提供当前摘要，应明确它来自学习层，不是 archaeology 的客观结论。

## 12. 五个反辉格式测试

### 终点删除测试

假设最终工件从未发布，当前事件的纳入、标题和篇幅是否会改变？若会，记录受终点支配。

### 分支交换测试

假设另一分支后来被采用，考古是否会把同一事件改名为成功或前身？若会，命名不是中性的。

### 时间截断测试

只使用该事件发生时已经存在的材料，当前描述还能成立吗？不能成立的部分属于后见分析。

### 主语恢复测试

把“错误、关键、证明、逼出”等词补上判断者。若找不到当时判断者，该词属于作者声音。

### 对称记录测试

相同类型的采用与未采用分支，是否保留同等结构信息？若胜出分支写细、其他分支只写“被放弃”，记录已经配重。

## 13. 用户记忆与后来接受

用户记忆可以提供搜索方向和当下评价，不能单独确定过去事实。应分别记录：

- 当前用户怎样回忆；
- 原始记录显示什么；
- 二者在哪些对象、时点或因果上不同。

后来一句“对”只证明当时对具体指代的接受。必须检查实际回复对象，不能扩展成对整段历史解释的认可。

## 14. 公开脱敏不改变事件关系

可以泛化：

- 人物与项目名；
- 日期、绝对路径和运行标识；
- 模型、供应商与内部调度；
- 不影响内容结构的数量和版本指纹。

不得因脱敏而：

- 合并两个不同事件；
- 改变提出者；
- 删除一个真实分支；
- 把直接引文改成更符合当前理论的转述；
- 隐藏会改变判断的时间关系。

无法兼顾公开与可核验时，宁可报告“存在一条已核对但不公开的记录”，不要编写替代故事。

## 15. 工作顺序

1. 建立语料全集和分支图；
2. 按来源与局部顺序制作中性事件账；
3. 独立重放工件版本和 diff；
4. 检查事件账是否含作者胜负词；
5. 做终点删除、分支交换、时间截断、主语恢复和对称记录测试；
6. 冻结 archaeology；
7. 从事件账提取带引用的 concept formation；
8. 从已标注推导中提炼 reflection；
9. 最后写 README 摘要；
10. 任何学习层新解释都不得反向修改 archaeology，除非发现了新的源材料或记录错误。

## 最终检查

- 是否仍以最终采用叶定义主历史？
- 是否有事件标题包含作者的成败判断？
- 是否用后来 notation 描述它出现前的文本？
- 是否把下一事件的反对写成上一事件自身的错误？
- 是否由时间邻近推断思想因果？
- 是否让胜出版本获得更多事实细节？
- 是否把当前理论结论放进“源事实”栏目？
- 是否所有学习判断都能回指事件并展示推导？
- 若删除最终成果，考古的内容与措辞是否仍基本不变？
- 生产规范是否仍只是被记录对象，而非历史裁判？
