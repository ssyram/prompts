# Reflection：从这次记录中能学什么

这是学习文件，不是发生史。每条判断都引用 [`archaeology.md`](archaeology.md) 的事件；引用证明发生了什么，后面的经验仍是当前推导。

## 1. 最大风险不是记错一句话，而是让终点支配整段历史

旧 archaeology 以最终采用叶、当前 `X|F` 和发布结果选择事件、命名阶段并分配价值。G28–G31 明确指出：理论回投只是更大问题的一种，任何后成价值框架都可能制造辉格式叙事。

**经验：**先写不含“重要、失败、前身、闭合”的事件账；概念谱系另写。

**边界：**绝对零组织不可能，但材料范围和省略规则必须与最终胜出结果无关。

## 2. 后来的反对不能改写先前事件的名字

E16 直接可见的是一组删除；E17 是随后用户说分析性与递归没有体现；E18 是文件又增加相关文字。

**经验：**保留三个事件及其回复关系，不把 E16 在考古层直接命名为“删过头”或“生产性失败”。这种判断只能在学习层展示桥接后提出。

## 3. 最终分支不是唯一历史

分支账显示，来源 P 和 C 都有含实质用户判断、但没有继续产生最终工件的分支；旧记录曾只把最终采用叶当主账。

**经验：**“后来沿用”只是分支状态，不是真实性和价值等级。未沿用分支也可能保存当时存在的替代问题与表述。

## 4. 描述旧文件时，只写当时可见结构

A08 与工件 S01 足以说明首版包含 `Object / Necessity / Directness`、停止条件和输出字段。

**经验：**考古到这里停止。它“没有 `X|F` 因而只是经验规则”是当前能力比较，应进入 concept formation，并同时承认隐含关系无法仅凭字面排除。

## 5. 单案例能支持细分析，不能自动获得历史中心地位

D01–D14 记录 callgraph 的字段删除、实现信息补充和信息/编码区分；D30 又明确把该案例带入理论询问。

**经验：**这足以支持“案例后来被引用并参与讨论”。要称它为不可替代中介，还需排除其他来源路径；不能由篇幅和记忆强度推出。

## 6. 过渡术语可以在学习层保留，不必塞回客观记录

E03–E12 直接使用自在/他在来讨论问题、方案、新整体与递归；E07–E11 同时限制该术语的哲学地位。

**经验：**术语后来未进入 SKILL，不等于历史上没有出现；它与现行角色的关系则属于后见概念谱系，必须明确标注。

## 7. 从案例推广时，要公开被删除和保留的前提

E24–E31 记录“父结构”、方案性疑问、`F / X / X|F / x_i`、用户认同和一次无关扩张。由这些事件可以提出一种当前解释：`X` 减少了“父结构”携带的方案与永久层级含义。

**经验：**普遍化不是把案例词换成抽象符号；应列出删掉了哪些案例前提、保留了哪些关系，以及还有哪些竞争分解。

## 8. 逻辑角色与操作方法必须分别取证

S10 已出现 `F`；F07–F24 才持续修改形成 `F` 的动作。

**经验：**一个角色在理论中必要，不推出某种恢复流程唯一，也不推出继续投入永远有收益。版本差异只能证明文本发生变化，方法效果还需行为比较。

## 9. 工件发布不能替代效果证明

F31–F34 记录候选复制、路由更新和发布；记录限制同时表明没有完成跨对象受控比较。

**经验：**“已发布”“可发现”“链接完整”是不同于“判断正确”“跨域稳定”的事实。

## 10. 学习文件也必须允许自己被考古纠正

G02–G24 记录 evolution 文档经历范围越界、配重争议、顺序修正和来源重读；G28–G31 又指出完整 archaeology 自身仍按当前成果组织历史。

**经验：**有引用不等于没有叙事。每次学习总结都应接受终点删除、分支交换、时间截断、主语恢复和对称记录测试。
