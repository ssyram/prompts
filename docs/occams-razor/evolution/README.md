# Occam's Razor：发生记录与学习文件

本目录分别保存 `/occams-razor` 的客观发生记录，以及从该记录出发所作的后见分析。它不是逐字公开私有会话，也不是第二套生产规范。

## 最高原则：不得用后成框架重写过去

考古的首要任务不是讲出一条有意义、连贯或通向当前成果的故事，而是在公开限制内尽可能恢复当时实际发生的对象、文本、次序、分支与修改。

任何后成的价值或解释框架——无论是当前 `X|F`、最终发布版本、后来用户评价、成功/失败标准还是哲学解释——都不得反过来决定：

- 哪些早期材料值得进入；
- 一个事件应叫什么；
- 哪些事件应占据更多篇幅；
- 两个相邻事件是否存在因果；
- 哪条分支代表进步、偏航、转折或闭合；
- 整段历史应以什么作为终点。

把后来理论投射到早期文本，只是这种辉格式叙事的一种表现。即使不用任何后来术语，只要以当前胜出结果选择材料、组织因果或分配价值，同样违反本原则。

严格考古可以记录：当时消息直接说了什么、工件直接包含什么、实际增加或删除了什么、消息怎样排序和分叉，以及后来哪条消息明确引用、接受或反对了它。后来的反对必须作为后来的独立事件记录，不能据此把较早事件直接命名为“错误”“过度裁剪”“前身”或“生产性失败”。

绝对零组织不可能：公开记录仍需确定范围、匿名化、排序并省略纯工具回显。可执行边界是，所有选择规则必须公开且不以最终胜出框架为标准；任何超出源记录的价值、因果、概念谱系或理论判断必须移到独立学习文件，并标明它是后见分析。

## 文档权限

| 文件 | 责任 | 允许的判断 | 禁止的越界 |
|---|---|---|---|
| [`archaeology.md`](archaeology.md) | 记录消息、工件、顺序、分支与修改 | 可观察内容、显式回复和记录缺口 | 历史地位、版本优劣、概念前身、必然链和当前终点 |
| [`concept-formation.md`](concept-formation.md) | 提出当前概念重构 | 带事件引用、推导桥和竞争解释的后见 claim | 把当前解释写成当时意识或唯一历史 |
| [`reflection.md`](reflection.md) | 提取可迁移经验 | 有事件依据并注明边界的方法判断 | 由单个案例直接推出普遍规律 |
| [`research-method.md`](research-method.md) | 约束考古与学习文件的生成 | 证据权限、分支方法和反辉格式测试 | 预先决定本案例应得出什么结论 |

文档依据关系保持单向：

```text
原始消息与同时期工件
→ archaeology.md：可观察发生记录
→ concept-formation.md / reflection.md：带事件引用的后见学习

research-method.md
→ 约束整个提取过程
```

现行生产工件是被记录的历史对象，不是裁定历史意义的依据。若学习文件与 archaeology 的可观察记录冲突，先修学习文件；不得为了保住现有解释而改写考古。

## 当前 archaeology 包含什么

- 四类来源的公开范围与结构性省略规则；
- 已识别的实质分支及其停止/继续状态；
- A01–G32 的继续分支消息记录、X01–X09 的未继续分支记录，以及 D00 的跨来源顺序；
- S01–S20 的工件快照账；
- 无法公开重放、无法逐字符归属及无法建立因果的位置。

它不再包含旧版中的概念谱系、历史地位、版本阶梯、“最小必要链”和十二项“实际形成物”。这些内容不是被判为无用，而是因证据权限不同被移出客观考古。

## 客观记录怎样反哺学习文件

可观察记录本身不产出价值结论。反哺发生在学习文件明确增加推导时：

1. `concept-formation.md` 用 claim card 记录当前主张、事件依据、推导桥、替代解释和证据状态；
2. `reflection.md` 把反辉格式、分支对称、后续反对不改写前事、角色与方法分开等经验接到具体事件；
3. 任何新解释都只能修改学习文件；只有发现新源材料或客观记录错误，才能反向修改 archaeology。

这种结构允许使用历史学习，同时防止学习结果吞掉历史。

1. [`research-method.md`](research-method.md)：先了解每层允许说什么；
2. [`archaeology.md`](archaeology.md)：阅读客观消息账、分支账与工件账；
