# Occam's Razor — Architecture（candidate P/D）

## Task Overview

**D.root：**在有根据的语境中取得被分析对象的完整有效规定，递归排除其内部无必要贡献的内容，得到相对于该语境的最小充分结果。

**上游 Q：**[`principles.md`](principles.md)。

**下游 I：**`.pending/occams-razor/SKILL.md`。

**范围：**本文件定义 `P + M + R`、判型、测试边界与 I obligations。O-R 只承担分析性压缩；新目标、非等价方案和未决取舍的综合属于相应 owner D/R 或 Q。

---

## 核心分析结构

每次 O-R 都包含四种位置：

- `F`：规定 `X` 在实际问题中何谓正确、充分和适用的权威问题设定，由已确认意图、相关事实、约束、用途与作用域构成；
- `X`：当前被压缩的整体；
- `X|F`：`X` 在 `F` 中成立的完整有效规定；
- `x_i`：`X` 中接受保留或排除判断的内容。

`X|F` 由两个来源共同形成：

- `J_F(X)`：`F` 凭什么支配对 `X` 的判断，以及据此怎样规定 `X` 的相关作用；
- `A(X)`：`X` 自身已经成立、且与本次判断相关的性质、结构和限制。

```text
J_F(X) + A(X) → X|F
X|F → 判断每个 x_i 的必要性
```

这里的“完整”只指足以决定当前裁剪的相关规定闭合，不包括全部历史、所有可能性质或未进入当前作用域的要求。`X` 是 `x_i` 的结构整体，不预设为某类方案；在 QPDI 设计任务中，它才可以具体表现为当前 D/M/I 对象，而 `X|F` 表现为该对象的 local contract。

`F` 必须正面给出 `X` 要实现的现实关系或结果、该关系成立所处的事实条件，以及判断成败的约束和边界。当前对话、开发与执行过程只是发现这些规定的证据来源，不是 `F` 本身；“生成过程消失后是否仍改变判断”只用于检验候选规定，不代替 `F` 的构造。

## P — Design Properties

### P.1 — `F` 被独立重建且分析立场合法、可能（local P）

`F` 必须正面规定：`X` 面对什么实际问题、要实现什么关系或结果、相关现实条件是什么、以什么边界判断正确与充分。每项规定都必须由用户授权、权威材料、明确约束或已观察事实支持，并共同形成可判断的 `X|F`。

`F` 从对象的实际用途重建，而不是沿用当前最显眼的讨论位置。用户在生成过程中作出的真实决定与确认的事实仍可进入 `F`；过程自身的组织、临时名称和只服务于生产活动的结构不得进入。去掉生成过程后，每项保留规定仍应改变对 `X` 的判断。

`X` 必须是该语境下真正接受裁剪的对象，整个立场必须能够推出实际取舍。若来源不足、关键解释冲突或要求不可能共同成立，O-R 不得贸然裁剪受影响内容；应提出最小异议或条件。普通而不影响裁剪的不确定性不触发异议流程。

### P.2 — `X|F` 同时承接外部辩护与对象内涵（local P）

不得只从 `F` 直接规定 `x_i`，也不得只用 `A(X)` 为既有内容辩护。`X|F` 必须同时说明：`F` 如何规定对 `X` 的判断与作用，以及 `X` 的自身规定如何参与这一关系。

只有实际参与当前关系的 `A(X)` 进入 `X|F`；对象的一般性质、历史附着物和当前无关能力不因此取得保留资格。`A(X)` 也不能只由待判断的 `x_i` 当前存在来证明，否则现状会循环地为自身辩护。`X|F` 改变时，只由旧规定支撑的下游判断失效。

### P.3 — 分析性 C2（local P）

O-R 是 SCCO 中第二个 C——**Concise（C2）**——的分析原则。它固定 `F`、`X` 与已经成立的 `X|F`，以同一个判据裁决任意单项或内容组合 `C ⊆ X`：若移除 `C` 及其专属后果、且不加入非等价内容后，剩余 `X` 仍完整满足 `X|F`，则 `C` 对当前整体不必要；否则不能据此删除。

删除、去重、等价合并、迁回真实 owner 或以权威引用代替复制，只是这个判据可能导出的形态，不构成完整分类。未列出的结构仍直接回到上述判据，不得把若干局部正确规则当成 C2 的定义。

O-R 不得增加新规范、发明候选、选择非等价方案或权衡不同覆盖。需要这些综合时，只暴露缺失义务并交回其 owner；综合完成后的新对象可以再次接受 O-R。

### P.4 — 本质递归（global P）

P.1–P.3 与 P.5 适用于当前作用域内每个被展开的复合 `x_i`。保留的 `x_i` 成为下一层 `X`；从上层 `X|F` 分配给它的 obligation 与它自己的相关规定共同形成下一层 `X|F`，同一分析关系重新成立。

递归深度由实际对象和作用域决定，在叶子处停止。不得把上层全部语境无差别传给子层，不得让子层依赖反向证明上层内容必要；上层规定改变后，其专属下游结果必须重新分析。

### P.5 — 最小充分与 SC 边界（local P）

Concise 是直接目标：每个保留的 `x_i` 都对 `X|F` 有当前论证作用，并且不能在保持已有语义、责任和保证的条件下继续删除或等价收缩。

Sound 与 Complete 是宣告“最小充分”必须成立、且裁剪不得破坏的边界。若初始对象尚不 Sound/Complete，O-R 可以暴露缺口并作不削弱已有 guarantee 的局部收缩，但不负责综合修复，也不得把结果称为最小充分。非等价设计之间的 Optimality 同样属于其 owner D/R。

## M — Operational Model

### M.1 — 正面重建独立 `F`

1. 从 `X` 实际面对的问题出发，识别用户要通过它实现的现实关系或结果。
2. 确定该关系所在的事实环境，以及什么条件分别构成正确、充分、适用与越界。
3. 为这些规定寻找有效来源：用户确认提供规范方向，权威材料与事实提供对象条件，明确约束限定作用域。
4. 再处理生成材料：保留其中已经取得上述地位的真实决定与事实；排除只解释如何讨论、开发或执行 `X` 的临时结构。
5. 用独立性反事实复核，而不以它代替构造：若生成过程消失，候选规定是否仍改变对 `X` 的判断。
6. 关键缺失、冲突或不可能性会改变裁剪时，提出最小异议；否则形成足以推出取舍的有界 `F`。

### M.2 — 确定 `X` 并形成 `X|F`

1. 指定真正接受裁剪的整体 `X`、作用域及实际使用者；区分对象内容与生成材料。
2. 建立 `J_F(X)`：说明 `F` 凭什么适用于 `X`、又会怎样改变对 `X` 的判断。
3. 提取 `F` 对 `X` 的相关要求，以及已经成立并参与当前关系的 `A(X)`。
4. 将二者合成为可推出具体保留与排除的 `X|F`；不能产生取舍的概括尚未完成。
5. 若形成 `X|F` 需要新增非等价规定或选择方案，停止分析并交回综合责任。

### M.3 — 分析 `x_i`

1. 只将 `X` 分解到足以提出实际删除候选的程度；候选可以是单项，也可以是任意有共同作用的内容组合 `C`。
2. 界定移除 `C` 时必然随之退出的专属后果，同时排除仍有其他根据的共享内容。
3. 比较移除前后的整体：若剩余 `X` 无需非等价补充仍满足全部 `X|F`，删除 `C` 或作已证明等价的收缩；否则保留。
4. 对下一个有根据的候选重复同一判断，直到当前作用域内没有仍受支持的删除候选。

内部依赖、重复、错位、引用关系和内容簇只用于发现候选，不能替代 `X|F` 下的整体删除判据。

### M.4 — 递归与重落根

对仍需展开的复合 `x_i`，只分配其实际承担的上层 obligation，以它为新的 `X`，重新执行 M.1–M.3。达到叶子或作用域边界时停止。

用户纠正、证据变化或上层裁剪改变 `F`、`J_F(X)` 或 `X|F` 时，删除旧分析的专属结果并从受影响层重新推导，不在旧框架上追加例外。

### M.5 — 重组与交付

重新组合各层结果，检查整体 Sound、Complete、接口、共享前提、实际 guarantee 和责任边界。只有 SC 已成立且无法继续作语义保持的删除或收缩时，才宣告最小充分。

在授权内直接落实成立的裁剪。默认交付压缩后的 `X`；只在分析立场、不能裁剪的理由、SC 缺口、综合义务或授权边界会改变用户行动时补充说明，不输出无消费者的内部分析形式。

## 正确 pattern

- **正面重建：**先从实际问题、预期关系、事实条件和成败边界构成 `F`，再排除生成语境干扰。
- **决定与过程分流：**保留生产过程中形成的真实决定和约束，排除只服务于生产活动的脚手架。
- **先整体后内容：**以 `J_F(X)` 与相关 `A(X)` 形成 `X|F`，再判断 `x_i`。
- **具体可否决：**工作理解必须推出实际取舍，并能由一个相反后果被纠正。
- **逐层分配：**子层只继承实际 obligation，不越过 local contract 直连根意图。
- **原则统摄：**具体可删形态只用于发现候选，所有候选最终都回到 `X|F` 下的同一删除判据。
- **整体重算：**上层根据变化或内容簇被裁剪后，重新检查完整对象及真实使用者。

## 典型失败 pattern

- **语境未迁移：**只从生成过程减去显眼脚手架而没有正面建立问题条件，或仅把临时概念改名后伪装成独立 `F`。
- **过度脱离：**把生成过程中已经确认、并真实约束 `X` 的决定与事实一并删除。
- **对象或内涵错置：**选错 `X`，工作理解不能推出取舍，或单边构造 `X|F`。
- **辩护结构失真：**让内容循环自证、越过局部 `X|F`，或用子层依赖证明上层选择。
- **局部列举替代原则：**把若干正确的保留或删除形态当作完整定义，使未列结构不再接受 `X|F` 的裁决。
- **分析偷换综合：**以精简为名新增规定、生成候选或决定非等价取舍。
- **充分性失守：**初始缺漏仍存在却宣称最小充分，或把本层应给出的判断转移给使用者。

## R — Reasoning

### Derivation

| Upstream | 推出 | 理由 |
|---|---|---|
| Q.I.1 + Q.A.1 + Q.E.1 | P.1 | 生成过程只提供有界证据且曾替代真实对象，因此 `F` 必须被独立重建，并形成合法、可判别且可能成立的语境—对象关系。 |
| Q.I.1 + Q.A.2 | P.2/P.3 | 必要性来自语境要求与对象自身规定的结合；O-R 只能分析既有规定。 |
| Q.A.2 + Q.E.1–Q.E.2 | P.4 | 每个复合内容都会形成新的局部整体，同一关系必须逐层重现。 |
| Q.I.1 + Q.E.2–Q.E.3 | P.5 | 局部理由与形式缩减不能证明整体最小充分，裁剪必须受 SC 约束。 |

### Satisfaction and Optimality

M.1 将生成材料重建为独立 `F`，M.2 形成 `X|F`，M.3 执行分析性 C2，M.4 保证 global P 的递归与重落根，M.5 保证 SC 和交付边界，因此 `M ⊨ P`。

只按词语裁剪会误认 `F`；只看外部需求或对象性质都会得到单边内涵；只检查根层不能保证内部 Concise；让 O-R 兼任综合则越出 C2。当前 M 只保留形成 `X|F`、分析 `x_i` 和递归复检所需的结构。

## 测试边界

使用最小样本分别检验：生成语境改变而对象用途不变时能否得到稳定 `F`；真实决定是否不会随脚手架被删除；立场无依据或不可能时能否提出异议；双边材料能否形成可裁剪的 `X|F`；未预先列举的冗余结构能否仍由统一判据识别；多层对象是否正确分配 obligation；上层纠正后是否清理旧结果；初始 SC 缺口是否阻止虚假完成；需要非等价新增时是否停止越界综合。

历史回放只评价误留、误删、越界综合、纠正成本和旧结构残留，不以是否展示术语或分析形式为指标。

## D → I obligations

| I 区域 | 必须落实的 D obligation |
|---|---|
| 核心模型 | 明确 `F`、`X`、`X|F`、`x_i` 的内部判断关系，不强制向用户展示符号。 |
| 立场与内涵 | P.1/P.2、M.1/M.2：脱离生成语境重建独立 `F`，检验合法性与可能性，再以双边来源形成 `X|F`。 |
| 分析与递归 | P.3/P.4、M.3/M.4：只作分析性 C2，并逐层重用而不泄漏上层语境。 |
| SC 与交付 | P.5/M.5：重组检查；不修复或洗白初始缺口；直接交付必要结果。 |
| 判型 | 把正确 pattern 写成动作，把失败 pattern 写成短而有排除力的禁止条件。 |

I 不得新增 Q/P 未推出的分析对象、综合职责、流程或固定输出要求。
