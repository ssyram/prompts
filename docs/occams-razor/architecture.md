# Occam's Razor — Architecture（candidate P/D）

## Task Overview

**D.root：**在有根据的语境中取得被分析对象的完整有效规定，递归排除其内部无必要贡献的内容，得到相对于该语境的最小充分结果。

**上游 Q：**[`principles.md`](principles.md)。

**下游 I：**[`current/occams-razor.md`](../../current/occams-razor.md)。

**范围：**本文件定义 `P + M + R`、判型、测试边界与 I obligations。O-R 只承担分析性压缩；新目标、非等价方案和未决取舍的综合属于相应 owner D/R 或 Q。

---

## 核心分析结构

每次 O-R 都包含四种位置：

- `X`：当前被压缩的整体；
- `F`：以当前既定的 `X` 为落点，经任务重校准恢复的有效目标链、当前实际处境和判断边界；
- `X|F`：`X` 在 `F` 中成立的完整有效规定；
- `x_i`：`X` 中接受保留或排除判断的内容。

`X|F` 由两个来源共同形成：

- `J_F(X)`：`F` 凭什么支配对 `X` 的判断，以及据此怎样规定 `X` 的相关作用；
- `A(X)`：`X` 自身已经成立、且与本次判断相关的性质、结构和限制。

```text
J_F(X) + A(X) → X|F
X|F → 判断每个 x_i 的必要性
```

这里的“完整”只指足以决定当前裁剪的相关规定闭合，不包括全部历史、所有可能性质或未进入当前作用域的要求。`X` 是 `x_i` 的结构整体，不预设为某类方案；在 QPDI 设计任务中，它才可以具体表现为当前 D/M/I 对象，而 `X|F` 表现为该对象的 local contract。

形成 `F` 前必须暂时搁置当前方案词汇和最近的局部焦点，重新阅读用户委托、裁决与实际证据，并在内部恢复四项坐标：

```text
最终目标：用户最终要实现、保护或避免什么
有效目标链：哪些仍有效的中间目标把最终目标逐层连接到 X
当前实际处境：现在真实存在什么，哪些只是计划、主张或待核状态
判断边界：本次作用域、约束、完成条件和权威来源
过程残留：与该目标链无关、已判错/放弃或未获承认的过程内容
```

前四项构成 `F`；最后一项被隔离而不取得判断权。已经成为 `X` 的实际性质进入 `A(X)`，而不是反写成 `F`。这张校准面是内部工作动作，不是固定输出格式。

## P — Design Properties

### P.1 — `F` 通过围绕 `X` 的任务重校准独立成立（local P）

根层 `X` 的范围通常由用户直接给定，递归子层则由上一层确定；开始判断其内容前，必须反向恢复它为何处于当前工作中：从用户最终目标出发，只保留仍有效且能逐层说明下一目标为何必要的中间目标，直到 `X` 的当前局部用途。最近焦点不得越过自己的父目标反向改写全局目的。

临时目标只有在父目标仍成立、分配关系有来源且当前责任未退出时才属于 `F`。已完成或已放弃的过程框架退出；其仍被当前工作依赖的已验证结果可以进入实际处境，用户确认的拒绝理由可以进入判断边界。已有方案和对象性质进入 `A(X)`，未获用户或权威材料承认的 AI 发明不取得判断权。

再从权威材料与证据恢复当前实际处境，明确作用域、约束和完成条件。若目标链断裂、来源不足、关键状态未明、解释冲突或要求不可能共同成立，O-R 不得猜测受影响内容；应提出最小异议。

### P.2 — `X|F` 同时承接外部辩护与对象内涵（local P）

不得只从 `F` 直接规定 `x_i`，也不得只用 `A(X)` 为既有内容辩护。`X|F` 必须同时说明：`F` 如何规定对 `X` 的判断与作用，以及 `X` 的自身规定如何参与这一关系。

只有实际参与当前关系的 `A(X)` 进入 `X|F`；对象的一般性质、历史附着物和当前无关能力不因此取得保留资格。`A(X)` 也不能只由待判断的 `x_i` 当前存在来证明，否则现状会循环地为自身辩护。`X|F` 改变时，只由旧规定支撑的下游判断失效。

### P.3 — 分析性 C2（local P）

O-R 是 SCCO 中第二个 C——**Concise（C2）**——的分析原则。它固定 `F`、`X` 与已经成立的 `X|F`，以同一个判据裁决任意单项或内容组合 `C ⊆ X`：只有能够证明移除 `C` 及其专属后果、且不加入非等价内容后，剩余 `X` 仍完整满足 `X|F`，才能判定 `C` 不必要。无法证明安全同样不得删除。

删除、去重、等价合并、迁回真实 owner 或以权威引用代替复制，只是这个判据可能导出的形态，不构成完整分类。未列出的结构仍直接回到上述判据，不得把若干局部正确规则当成 C2 的定义。

O-R 不得增加新规范、发明候选、选择非等价方案或权衡不同覆盖。需要这些综合时，只暴露缺失义务并交回其 owner；综合完成后的新对象可以再次接受 O-R。

### P.4 — 本质递归（global P）

P.1–P.3 与 P.5 适用于当前作用域内每个被展开的复合 `x_i`。保留的 `x_i` 成为下一层 `X`；从上层 `X|F` 分配给它的 obligation 与它自己的相关规定共同形成下一层 `X|F`，同一分析关系重新成立。

递归深度由实际对象和作用域决定，在叶子处停止。不得把上层全部语境无差别传给子层，不得让子层依赖反向证明上层内容必要；上层规定改变后，其专属下游结果必须重新分析。

### P.5 — 最小充分与 SC 边界（local P）

Concise 是直接目标：每个保留的 `x_i` 都对 `X|F` 有当前论证作用，并且不能在保持已有语义、责任和保证的条件下继续删除或等价收缩。

Sound 与 Complete 是宣告“最小充分”必须成立、且裁剪不得破坏的边界。若初始对象尚不 Sound/Complete，O-R 可以暴露缺口并作不削弱已有 guarantee 的局部收缩，但不负责综合修复，也不得把结果称为最小充分。非等价设计之间的 Optimality 同样属于其 owner D/R。

## M — Operational Model

### M.1 — 围绕 `X` 重校准并划定 `F`

1. 根层采用用户给定的 `X` 与范围，递归层采用上一层确定的子对象；只有边界实质不明且会改变裁剪时才提出最小异议，不自行扩大对象。
2. 暂时搁置当前方案词汇和最近焦点，重读用户请求、纠正、接受与拒绝，恢复最终目标。
3. 从 `X` 的直接局部用途开始逐级追问“它当前服务哪个仍有效目标、该目标又为何仍被需要”，直到接回最终目标；每一跳都须有用户裁决、既有设计或实际任务关系支持。
4. 核对现有工件与验证证据，恢复当前真实处境，严格区分想要、计划、声称、已落实、已验证和已接受；写明约束、完成条件和来源优先级。
5. 清除不在有效目标链上的历史：无关 LLM 内容、已判错或放弃的框架、只为执行方便产生的结构，以及未获承认的 AI 发明。保留仍被当前链依赖的已验证结果与已确认拒绝边界；把 `X` 的现有性质交给 `A(X)`。
6. 以“最终目标 → 有效中间目标 → `X` 局部用途”加实际处境和判断边界形成 `F`。若链路或关键事实无法成立，停止受影响裁剪而不继续猜测。

### M.2 — 形成 `X|F`

1. 复核当前既定的 `X`、作用域及实际使用者；不因分析中发现其他对象而悄悄扩张范围。
2. 建立 `J_F(X)`：说明 `F` 凭什么适用于 `X`、又会怎样改变对 `X` 的判断。
3. 提取 `F` 对 `X` 的相关要求，以及已经成立并参与当前关系的 `A(X)`。
4. 将二者合成为可推出具体保留与排除的 `X|F`；不能产生取舍的概括尚未完成。
5. 若形成 `X|F` 需要新增非等价规定或选择方案，停止分析并交回综合责任。

### M.3 — 分析 `x_i`

1. 只将 `X` 分解到足以提出实际删除候选的程度；候选可以是单项，也可以是任意有共同作用的内容组合 `C`。
2. 界定移除 `C` 时必然随之退出的专属后果，并检查剩余内容依赖的定义、来源、前提与引用是否仍然可达。
3. 只有能够证明剩余 `X` 无需非等价补充仍满足全部 `X|F` 时，才删除 `C` 或作已证明等价的收缩；定义或引用悬空、证据不足或仍有相关疑问时保留。
4. 对下一个有根据的候选重复同一判断，直到当前作用域内没有仍能证明安全的删除候选。

内部依赖、重复、错位、引用关系和内容簇只用于发现候选，不能替代 `X|F` 下的整体删除判据。

### M.4 — 递归与重落根

对仍需展开的复合 `x_i`，只分配其实际承担的上层 obligation，以它为新的 `X`，重新执行 M.1–M.3。达到叶子或作用域边界时停止。

用户纠正、证据变化或上层裁剪改变 `F`、`J_F(X)` 或 `X|F` 时，删除旧分析的专属结果并从受影响层重新推导，不在旧框架上追加例外。

### M.5 — 重组与交付

重新组合各层结果，检查整体 Sound、Complete、定义与引用闭合、接口、共享前提、实际 guarantee 和责任边界。只有 SC 已成立且无法继续作语义保持的删除或收缩时，才宣告最小充分。

在授权内直接落实成立的裁剪。默认交付压缩后的 `X`；只在分析立场、不能裁剪的理由、SC 缺口、综合义务或授权边界会改变用户行动时补充说明，不输出无消费者的内部分析形式。

交付前固定复查本轮实际改动：若仍有可证安全的裁剪则回到 M.3；若本轮改动使整体或任一已触发子情形留下未定义、未解释、失去依据或不再充分的内容，则撤回或修正该改动并重新执行 M.5；原有缺口仍按 P.5 暴露。循环直到无进一步可证安全裁剪且本轮改动未破坏 SC。

## 正确 pattern

- **沿链重校准：**从 `X` 的局部用途逐级接回仍有效的中间目标和最终目标，再恢复实际处境与边界。
- **过程清场：**删除与有效目标链无关、已判错/放弃或未获承认的过程框架，只保留仍有当前效力的结果与边界。
- **先整体后内容：**以 `J_F(X)` 与相关 `A(X)` 形成 `X|F`，再判断 `x_i`。
- **具体可否决：**工作理解必须推出实际取舍，并能由一个相反后果被纠正。
- **逐层分配：**子层只继承实际 obligation，不越过 local contract 直连根意图。
- **原则统摄：**具体可删形态只用于发现候选，所有候选最终都回到 `X|F` 下的同一删除判据。
- **整体与定义闭合：**裁剪后重新检查完整对象、真实使用者，以及所有保留符号、术语、前提和引用的定义来源。

## 典型失败 pattern

- **目标链断裂或倒置：**局部目标没有有效父目标，或最近焦点越过父链冒充最终委托。
- **过程残留取得权威：**无关历史、已判错/放弃框架、过程发明或未获承认的 AI 概念继续规定 `X`。
- **状态或对象错置：**把计划或主张写成事实，把 `X` 的既有性质反写成 `F`，或悄悄改变用户给定的 `X`。
- **辩护结构失真：**让内容循环自证、越过局部 `X|F`，或用子层依赖证明上层选择。
- **局部列举替代原则：**把若干正确的保留或删除形态当作完整定义，使未列结构不再接受 `X|F` 的裁决。
- **定义或引用悬空：**引入未定义符号，或删除定义、来源与前提后仍保留依赖它们的内容。
- **分析偷换综合：**以精简为名新增规定、生成候选或决定非等价取舍。
- **充分性失守：**初始缺漏仍存在却宣称最小充分，或把本层应给出的判断转移给使用者。

## R — Reasoning

### Empirical basis

P.1/M.1 借鉴的经验对象是 `/recalibration` 内容 SHA-256 `cd8604c4eee833a0845398d6655522097106bc1d83290a03f6f03c0da2ddc7ab`。这里只采用其已写明的重校准动作，不形成运行时依赖；未来版本不会自动改变本设计，须重新审阅后才更新 hash 与承接关系。

### Derivation

| Upstream | 推出 | 理由 |
|---|---|---|
| Q.I.1 + Q.A.1 + Q.E.1/Q.E.4 | P.1 | 生成过程曾替代真实对象，而重校准已有有限正效应；因此从最终目标、有效中间目标和实际状态重建 `F`，并保留来源核对。 |
| Q.I.1 + Q.A.2 | P.2/P.3 | 必要性来自语境要求与对象自身规定的结合；O-R 只能分析既有规定。 |
| Q.A.2 + Q.E.1–Q.E.2 | P.4 | 每个复合内容都会形成新的局部整体，同一关系必须逐层重现。 |
| Q.I.1 + Q.E.2–Q.E.3 | P.5 | 局部理由与形式缩减不能证明整体最小充分，裁剪必须受 SC 约束。 |

### Satisfaction and Optimality

M.1 围绕用户给定的 `X` 恢复有效目标链、实际处境与边界，M.2 形成 `X|F`，M.3 执行分析性 C2，M.4 保证递归与重落根，M.5 保证 SC 和交付边界，因此 `M ⊨ P`。

只按词语裁剪会误认 `F`；只看外部需求或对象性质都会得到单边内涵；只检查根层不能保证内部 Concise；让 O-R 兼任综合则越出 C2。当前 M 只保留形成 `X|F`、分析 `x_i` 和递归复检所需的结构。

## 测试边界

使用最小样本分别检验：根层用户给定的 `X` 与递归子层边界是否稳定；局部目标能否接回最终目标；错误框架与未承认 AI 发明是否清除；事实状态能否分开；有效结果是否保留；双边材料能否形成 `X|F`；未列冗余能否识别；定义或来源被删时依赖内容是否阻止裁剪；初始 SC 缺口是否阻止虚假完成。

历史回放只评价误留、误删、越界综合、纠正成本和旧结构残留，不以是否展示术语或分析形式为指标。真实成功与失败样本见 [`context-recalibration-cases.md`](context-recalibration-cases.md)。

## D → I obligations

| I 区域 | 必须落实的 D obligation |
|---|---|
| 核心模型 | 明确 `F`、`X`、`X|F`、`x_i` 的内部判断关系，不强制向用户展示符号。 |
| 立场与内涵 | P.1/P.2、M.1/M.2：围绕当前既定 `X` 恢复有效目标链与实际处境，清除过程残留，分流 `A(X)`，再形成 `X|F`。 |
| 分析与递归 | P.3/P.4、M.3/M.4：只作分析性 C2，并逐层重用而不泄漏上层语境。 |
| SC 与交付 | P.5/M.5：重组并检查定义、来源和引用闭合；不修复或洗白初始缺口；直接交付必要结果。 |
| 判型 | 把正确 pattern 写成动作，把失败 pattern 写成短而有排除力的禁止条件。 |

I 不得新增 Q/P 未推出的分析对象、综合职责、流程或固定输出要求。
