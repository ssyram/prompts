# 奥卡姆剃刀

在不损害真实目的、正确性和完整性的前提下，排除既有对象中没有必要贡献的内容。对齐任务难度和必要复杂度，以期实现最小充分。

## 内部骨架

以下关系只用于内部判断；除非解释裁剪边界确实需要，不向用户输出这些符号或推导骨架，也不把它们混入压缩后的正文：

- `X`：当前被考察的整体，潜在压缩对象；
- `F`：围绕当前既定的 `X`，重新恢复出的有效目标链、当前实际处境和判断边界；
- `A(X)`：`X` 已经成立、并与本次判断相关的性质、结构和限制；它们已经存在不等于它们必然应被保留；
- `X|F`：`F` 对 `X` 的规定与 `A(X)` 共同形成的有效内涵；
- `x_i`：`X` 中接受保留或排除判断的内容。

后文使用的符号必须在这里或首次出现处定义；不得让未定义符号、术语或引用进入判断或最终结果。

核心判断流程：

```text
重建干净的实际语境下的 F
→ 识别 F 凭什么适用于 X、怎样规定对 X 的判断
  + A(X)
→ X|F
→ 在此前提下判断各 x_i 是否必要
```

## 1. 围绕 `X` 重校准并划定 `F`

根层 `X` 及其范围通常由用户直接给出；递归子层由上一层确定。先准确采用当前对象，不因分析中出现其他问题而扩大范围。只有边界实质不明且会改变裁剪时才提出最小异议。

1. 暂时搁置当前方案词汇和最近焦点，重新回忆、校准、有需要时重读相关历史材料等，用户对这项工作的请求、纠正、接受与拒绝，恢复他最终要改变、实现、保护或避免什么。
2. 从 `X` 的直接用途开始逐级追问：它当前服务哪个仍有效的临时或局部目标？这个目标又为何仍被需要？继续直到接回最终目标。每一跳都必须有用户裁决、既有设计关系或实际任务关系支持。
3. 核对现有工件、权威材料和验证证据，恢复当前真实处境；严格区分想要、计划、声称、已落实、已验证和已接受，并写明作用约束与完成条件。
4. 清理不在有效目标链上的历史：与 `X` 无关的 LLM 内容、已判错或放弃的框架、只为过程方便产生的结构，以及未获用户或权威材料承认的 AI 发明。已退出过程若留下当前仍依赖的验证结果，只保留结果；用户确认的拒绝理由仍可成为边界。
5. 把 `X` 的既有性质交给 `A(X)`，不让它们仅因已经存在就反向规定 `F`。
6. 如果找不到 `X` 的实际合理需求环境 `F`，应停止裁剪并向用户提出最小异议 -- 提议重新建立 `X` 的实际用途需求，或者建议用户将 `X` 材料进行整体重新评估。

可在内部临时写成：

```text
X：
最终目标：
有效目标链：最终目标 → 仍有效的中间目标 → X 的局部用途
当前实际处境：
判断边界：
排除的过程语境：
```

`F` 由有效目标链、实际处境和判断边界构成；最后一项只用于清场，不取得判断权。这不是向用户输出的固定格式。若目标链、关键事实或约束无法成立，停止受影响的裁剪并提出最小异议；与裁剪无关的不确定性不触发询问。

### 重校准 `F` 的例子

以下例子只演示同一动作，不构成场景分类。

**设计说明：**`X` 是用户指定的一份待压缩设计。最终目标是让接手者正确实现；当前局部目标是消除会妨碍实现的歧义。

- **成功：**“消除歧义”能接回“正确实现”，所以进入有效目标链；某条审阅意见若揭示真实歧义，其已确认结论进入实际处境。审阅顺序、已驳回意见和为处理意见建立的任务分组被清除；现有章节与方案性质交给 `A(X)`。
- **失败：**把“处理全部审阅意见”升格为目标，使已驳回意见和审阅组织继续支配 `X`；或者因“审阅”是过程就把仍未解决的真实歧义一起删除。

**研究摘要：**`X` 是用户指定的摘要。最终目标是支持一项选择；“核实某个决定性条件”是当前仍有效的中间目标。

- **成功：**把这项核实接回实际选择，保留其已验证结果与证据边界；清除无关 LLM 历史、失败检索路径、被否定猜测和未获承认的 AI 分类。
- **失败：**按检索分组重造用户问题，把失败路径和中间猜测留在 `F`；或者看见它们是临时内容，就连当前选择仍依赖的核实结果也一起丢掉。

成功不在于填满模板，而在于恢复一条有来源、仍有效并确实落到 `X` 的目标链，同时让已经退出的过程不再支配判断。

## 2. 形成 `X|F`

复核当前既定的 `X`、实际用途和作用边界，不悄悄扩张范围。说明 `F` 凭什么适用于 `X`，以及它会怎样改变对 `X` 的判断；该理解必须能推出实际保留或排除。

同时取得 `F` 对 `X` 的相关规定，以及 `X` 已经成立并实际参与本次判断的性质。后者不能只由待判断内容当前存在来证明。

只纳入足以决定当前裁剪的规定，不粘连全部历史、一般性质或作用域外要求。不得只按 `F` 臆造内部内容，也不得只因内容已经属于 `X` 就保留它。

若形成 `X|F` 必须增加未给定的规定、生成候选或作新的取舍，停止把它称为裁剪，把该决定留给原问题的决策者；决定形成后再分析新对象。

### 形成 `X|F` 的例子

以下继续使用前述场景，但仍只解释共同关系。

**设计说明：**`F` 要求接手者能够正确实现对象；`X` 自身是传递稳定设计规定的说明，而不是实现本身。

- **成功的 `X|F`：**说明应完整传递实现所需行为、边界和已确认决定，并采用足以让接手者无歧义理解的表达；它不因此虚构尚未决定的实现细节。
- **失败的 `X|F`：**只从 `F` 推出一套新的具体实现；或者只因 `X` 现有章节符合某种说明形式，就把所有章节视为必要。

**研究摘要：**`F` 要求支持一项实际选择；`X` 自身是压缩证据及结论的摘要，其主张必须保留相应依据与不确定性。

- **成功的 `X|F`：**保留足以支撑选择的相关结论、证据状态和真实边界，并删除不改变选择或可信度的过程材料。
- **失败的 `X|F`：**只复述想得到的结论而丢失证据关系；或者因为材料已经被搜集，就把全部材料当成摘要的固有内容。

## 3. 分析 `x_i`

对任意单项或内容组合 `C`，先界定删除它时必然随之退出的专属后果，并检查剩余内容依赖的定义、来源、前提和引用是否仍然可达。然后只问：

> 删除 `C` 且不增加未给定内容以后，能否证明剩余 `X` 仍完整满足 `X|F`？

只有能够证明答案为“是”时才删除 `C`，或作已经证明不改变意义和用途的收缩。证明不了删除安全、定义或引用变成悬空、或者仍存在相关疑问时，都不能据此删除；必要时保留该项并说明阻断判断的缺口。

对下一个有根据的候选重复，直到当前作用域内没有仍能证明安全的删除候选。内部依赖、重复、错位、引用关系和内容簇只能帮助发现候选，不是完整分类；所有候选都必须回到同一个 `X|F` 判据。

## 4. 逐层重用

对仍需展开的复合 `x_i`，只把它实际承担的要求作为子层 `F`，以它为新的 `X`，重新形成 `X|F` 并分析其内部内容。到达叶子或当前作用域边界时停止。

不要把上层全部语境无差别传给子层，也不要用子层依赖反向证明上层内容必要。用户纠正、证据变化或上层裁剪改变当前规定后，删除旧理解的专属结果并重新推导，不在旧框架上追加例外。

## 5. 重组与交付

每次裁剪后重新组合整个结果，检查其是否仍真实、完整、满足约束并足以供实际使用；所有保留的符号、术语、引用和前提都必须仍有可达定义或来源。若使用者必须补做本次工作应完成的判断，压缩就不充分。

若原对象本来缺少必要内容，可以指出缺口，并只作能够证明不会削弱已有作用的局部裁剪；不要自行补造缺失内容，也不要把结果称为最小充分。

在已有授权内直接落实成立的裁剪。默认交付压缩后的 `X`；只有判断前提、不能裁剪的理由、原有缺口或授权边界会改变用户行动时才补充说明。

实际交付前固定复查本轮改动：还能否证明其他内容可以安全删除；本轮删除或收缩是否使整体或任一已触发子情形留下未定义、未解释、失去依据或不再充分的内容。前者成立则回到第 3 节继续裁剪；后者由本轮改动造成则撤回或修正该改动，再重新执行第 5 节；原有缺口仍按上文暴露。循环直到没有进一步可证安全的裁剪，且本轮改动没有破坏充分性。

## 典型失败 pattern

- **目标链断裂或倒置：**局部目标没有有效父目标，或最近焦点越过父链冒充最终委托。
- **过程残留取得权威：**无关历史、已判错/放弃框架、过程发明或未获承认的 AI 概念继续规定 `X`。
- **状态或对象错置：**把计划或主张写成事实，把 `X` 的既有性质反写成 `F`，或悄悄改变用户给定的 `X`。
- **辩护结构失真：**让内容循环自证、越过局部 `X|F`，或用子层依赖证明上层内容。
- **局部列举替代原则：**把若干正确的保留或删除形态当作完整定义，使未列结构不再接受 `X|F` 的判断。
- **定义或引用悬空：**使用未定义符号，或删除定义、来源与前提后仍保留依赖它们的内容。
- **裁剪偷换建构：**以精简为名增加规定、生成候选或决定新的取舍。
- **充分性失守：**原有缺口仍存在却宣称最小充分，或把本次应完成的判断转移给使用者。
